# Workflow Copy — Vietnamese (Canonical)

> Status: active reference. Phase 4.4 (plan §22.9.E, 2026-05-23).
>
> This file is the canonical source of Vietnamese user-facing copy for the
> Home Services mobile app workflow. Mobile surfaces currently keep many
> strings inline in `apps/mobile/components/customer/customer-surfaces.tsx`
> and `apps/mobile/components/worker/worker-surfaces.tsx`. The next
> incremental refactor (Phase 4.4 follow-up) extracts these into
> `apps/mobile/lib/copy/customer-copy.ts` and
> `apps/mobile/lib/copy/worker-copy.ts`, importing the strings listed here.
>
> Until the TS extraction lands, when changing user-facing copy:
> 1. Update this file first (or in the same PR).
> 2. Update inline strings to match.
> 3. Run static gates that assert the wording (e.g. price disclaimer).

## Hard locked strings (do not change without product approval)

- Price disclaimer (Rule #4): `Đây là ước tính do Kael tính theo dữ liệu hiện có. Kael có thể cập nhật khi có bằng chứng phạm vi mới.`
- Unsupported service decline: `Chúng tôi hiện chỉ hỗ trợ sửa điện, sửa nước và vệ sinh. Vui lòng quay lại khi chúng tôi mở rộng dịch vụ.`
- Kael final-price authority badge (Phase 2.0): `Kael tự tính` / `Ước tính mới do Kael tính lại dựa trên phạm vi thợ báo cáo.`

| Step | Surface | Key copy |
|---|---|---|
| A0 Auth | LoginRoleSurface | "Khách" / "Thợ" gate; email/password labels per `auth-surfaces.tsx`. |

| A14 Review | CustomerHistorySurface Done tab | Stars + tag chips (`Đúng giờ`, `Lịch sự`, `Sạch sẽ`, `Giải thích rõ`, `Giá hợp lý`) + comment (Phase 4.2). |
