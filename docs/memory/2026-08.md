## 2026-08-05 Plan §49 review turn — installing deps exposed two real D4 regressions

- **Regression A — the integration suites stopped skipping and started failing.** `resolveIntegrationTarget` falls back to `http://127.0.0.1:54321` when no URL is set, and returned `ok: true` even with the local stack down, so `describeReal` became `describe` and 50 tests fired at a dead loopback port. The fourth file (`rls-per-actor`) had been missing from the list all along.
- **Gate-design lesson, the durable one: "the file was not edited" is not the same as "the test still passes".** §49's G6 read *"72 schema text-assertion files not touched by a single byte (`git diff --stat` proves it)"* — and it reported **green while the suite was red**, because a deliberate refactor elsewhere invalidated an assertion inside an untouched file. A gate that measures diff-emptiness cannot see that. G6 now measures `pnpm test:api` exit 0, and states that editing an assertion is legitimate only when it tracks a deliberate refactor and preserves the check's purpose.
