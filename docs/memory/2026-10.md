## 2026-10-05 Kael Chat composers: native auto-grow, Return inserts a line

- **Symptom (Tu, Build 51 on iPhone).** In both Customer and Worker Kael Chat, a long draft stayed one line tall and earlier lines scrolled up out of view; the box never grew.
- **Root cause (strong hypothesis, not reproducible here).** Both composers pinned the TextInput `height` to the `onContentSizeChange` measurement and kept `scrollEnabled` off until the 124 cap. A fixed-height iOS text view with scrolling off reports its own frame as content size, so it never grew. The two earlier fixes (`2096458`, `621916d`) kept that design and were checked on web only, where the measurement is right.
- **Fix.** Shared `components/ui/kael-composer-input-height.ts` (`useKaelComposerInputSizing`). Native gets only `minHeight 44 / maxHeight 124` with scrolling on, so it sizes to its text. Web keeps the measured height. Return = newline on native (Tu's choice); web keeps Enter = send, Shift+Enter = newline.
- **Test trap found and closed.** `withPillarContext` is synchronous. `worker-kael-composer-layout-pillar-test.tsx` awaited it with async bodies (7 cases), so every assertion after the first `await` ran detached and could never fail. It surfaced as a red in an unrelated later suite (code frame pointing at the wrong file). A local awaited wrapper fixed it, and a web-reset mutation then turned the post-send assertion red as it should.
- **Verified.** Mutations observed red: native pinned height and native Return=send (P205 + P298 native cases); web reset (both web cases). `pnpm test:mobile` 239 suites / 2284 tests, `type-check:mobile`, eslint, `lint:comments`, pillar registry. Web localhost: both composers grow 44 → 64 → 124 with the bottom edge fixed, then scroll inside; light and dark.
- **Gaps.** iOS/Android not run here: the TestFlight build after this is the real proof. The Customer dark composer text looks low-contrast on web only: the shared web style forces `WebkitTextFillColor`. This was inferred from code as pre-existing, not re-checked against the old build.
