# Agent Workbench

Use this folder for temporary probes, fixtures, and one-off scripts while an agent is exploring.

Files added here are ignored by Git by default. If a probe becomes useful, promote it intentionally into the correct production owner path or a real test file after passing the relevant NestScout protocol gates.

Do not store secrets, `.env` files, raw customer data, worker identity data, full addresses, provider keys, or production-only credentials here.
